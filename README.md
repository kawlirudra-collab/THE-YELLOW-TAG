# THE YELLOW TAG // ARCHIVE HARDWARE PREVIEW [GROUNDED MAY 2026]

Interactive 2.5D spatial D2C concept preview website for **THE YELLOW TAG** — an ironic, ultra-premium travel hardware brand born from the cultural trauma of budget air travel.

## Tech Stack
- **Vite + React + TypeScript**
- **Tailwind CSS**
- **Framer Motion** (2.5D spring parallax, shared-origin bay zoom, and optical scanner mascot morph)
- **Typography**: `Inter` & `JetBrains Mono`

## Getting Started

```bash
npm install
npm run dev
```
